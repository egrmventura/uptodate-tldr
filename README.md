# Up To Date TL;DR

## Overview
This is an exploration of scraping and aggregating hot posts on a daily basis, to then filter out the noise and rank the top 2-6 articles in TL;DR format by independent email or blog posts.

### Variables (initial and potential)
#### intial
- **Topics**: AI, ML, Claude Code/Codex/Antigravity, etc.
- **Number Range**: Number of articles summarized *(default 2 min 6 max)*
- **Scheduling**: Daily, Weekdays, Even/Odd Days, Custom DOW
- **Personality**: Custom prompts to interperet the personality and writing styles of the user for a relateable post

#### potential
- **Location**: Default Email; anticipate blog and social media
- **Topics**: *Wider genre ranges*
- **Sources**: Default Reddit, LinkedIn, Google News; Expand to url provided
- **Specialty Trigger**: Urgent notifications on high profile articles
