Goal: add a repeatable seeding routine (a `--seed` path or documented `--backfill` invocation) that runs the analysis pipeline across a defined set of past date windows for one or more topics and persists `GroupAnalysis` rows into `output/analyses.db`. Key constraint: seeding must be idempotent and preserve backfill correctness — `period_start`/`period_end` come from article publication dates (not run date), and re-running the same window must not create duplicates, relying on the existing `UNIQUE(topic, period_start, period_end) + INSERT OR IGNORE`. Validate by running the seed twice over the same range and asserting the row count in `analyses.db` is identical after both runs, and that `--timeline` renders the seeded periods in chronological order by `period_start`.
