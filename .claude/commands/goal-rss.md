Implement an RSS/Atom feed source. Goal: add a `sources/rss.py` module exposing a `Source` subclass whose `fetch(topic, config)` reads one or more feed URLs from `config.yaml`, parses entries with `feedparser`, and maps each entry to the shared `Item` dataclass (title, url, author, published timestamp via `parse_timestamp()`, short excerpt from summary/description). Key constraint: it must never raise — wrap all network and parse I/O in try/except that logs and returns `[]`, per the `Source` ABC contract, and register the new source in *both* the `_SOURCES` dict in `main.py` and the `sources:` section of `config.yaml` (the dual registry). Validate with a unit test that feeds 2-3 saved feed XML fixtures (one Atom, one RSS 2.0, one malformed) through `fetch` offline, asserting correct field extraction and that the malformed feed yields `[]` without crashing.
