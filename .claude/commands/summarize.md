Produce or refresh a TLDR digest on demand. Goal: given a topic (and optional date window), run ingest → rank → summarize for that topic and write the digest markdown, reusing the existing `summarizer.py` persona-from-config path without touching the analysis pipeline. Key constraint: summarization failure raises (there is nothing to deliver without a digest), while source failures stay isolated (`[]`); the persona and `top_n` come from `config.yaml`/env overrides, never hardcoded. Validate by running against a small fixed item set with a mocked Anthropic response, asserting the digest contains the expected number of ranked items and that a summarizer API failure surfaces as a raised error rather than a silent empty file.
