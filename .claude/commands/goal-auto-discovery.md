Add source auto-discovery to replace the dual registry. Goal: implement discovery so that `Source` subclasses under `sources/` are found and instantiated automatically at startup, eliminating the need to hand-edit the `_SOURCES` dict in `main.py` while still honoring which sources are enabled/configured in `config.yaml`. Key constraint: discovery must be opt-in per source via config (a disabled or unconfigured source is never instantiated), must preserve current behavior for existing HackerNews/arXiv/RSS sources, and must keep the fragile LinkedIn source disabled by default. Validate with a test that points discovery at a fixture package containing a valid `Source` subclass and a non-source class, asserting only the valid enabled source is registered and that a config-disabled source is excluded.
