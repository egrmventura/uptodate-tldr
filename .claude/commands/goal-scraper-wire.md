Wire the full-text scraper into the ingestion stage. Goal: connect the scraper module (from goal-scraper) so that after sources return `Item`s with URLs, the pipeline optionally enriches each item with full body text before ranking/summarization, gated by a `scraping.enabled` flag in `config.yaml`. Key constraint: enrichment must be best-effort and isolated — a failed or paywalled fetch leaves the item's existing excerpt intact and never aborts the run, and scraping runs through the same `ThreadPoolExecutor` parallelism already used for sources. Validate with a test that runs a small item list through the enrichment step using mocked scraper responses (one success, one skip/blocked), asserting the successful item gains body text and the blocked item is unchanged and still present.
